# DM-IMU-L1 的 CAD 模型与姿态坐标

三维窗口直接显示达妙官方 `DM-IMU-L1-V1.0-3d.STEP` 的三角网格，包括壳体、四个安装孔、USB Type-C 插座、侧面 CAN/485 接插件和导光柱。不是以裸 PCB 或通用方块代替产品。外形为 26 × 36 × 9 mm；顶面标识由本项目重新绘制，材质颜色也是本项目的显示样式。

## 准备与缓存

```sh
python scripts/prepare_model.py --install
```

首次运行下载约 39 MB 官方 STEP，并在 `downloads/models/converter-env` 创建独立的 OpenCascade 转换环境。转换依赖只用于准备模型，普通应用与 Agent 接口不需要导入 CAD 库。运行环境至少需要 Python 3.11（`hashlib.file_digest`）。第二次运行校验约 4.83 MB 缓存后直接结束。若已有 CAD Python，可用 `--cad-python /path/to/python`，或者 `--step /path/to/official.STEP` 指定已下载文件。`DMIMU_MODEL_CACHE` 可以指定缓存目录，`--force` 强制重建。缺少模型时界面明确显示准备命令，仍可正常采集和分析数据。

官方库未提供覆盖该 CAD 的明确再分发许可证，因此源 STEP 与转换后的网格均在 `downloads/` 下，忽略 Git 跟踪。仓库发布的是下载、转换与显示程序。模型来自 [达妙官方仓库](https://gitee.com/kit-miao/dm-imu)，固定 Git blob `b0ede7e62f2f40b8ad61680f821a4e8a1d280584`。

Gitee blob API 对文件中的少量非 ASCII 产品名称进行文本转码，因此 API 解码后的文件长度（39,334,534 字节）和 tree 中的原始 blob 长度（39,334,514 字节）略有差异。转换工具固定验证 **API 交付内容**的 SHA-256 `a3485deed48e3324e956bc7584dd42d9abf3d2cbbc5ef9e4d02dec3c99b81ddb`，并未将其称为原始 Git 对象校验。几何坐标没有作文本修改。

## 坐标依据

依据实际模块的印刷坐标，**+X 朝 Type-C，+Y 沿顶盖长边，+Z 朝顶盖外侧**，满足右手系。已从官方 CAD 的四个侧面逐一检查接口位置：CAD 的 USB 在 `-Z` 边、顶盖朝 `+Y`、长边沿 `X`。因此转换公式为：

```
X_device = -Z_cad
Y_device = -X_cad
Z_device =  Y_cad
```

该旋转矩阵的行列式为 +1，没有镜像。视觉原点设在壳体几何中心：CAD Y 的中心值是 -2.5 mm。厂商没有公开敏感元件中心的位置，这里不声称几何中心等于测量原点。三维场景中的模型单位为 10 mm。

准备工具先将网格转换为设备坐标。显示时只进行一次设备 Z-up 到 Three.js Y-up 的基变换（绕 X 轴 -90°）；设备四元数按 `w,x,y,z` 读取，显示乘积为 `basis * reference * quaternion`。欧拉角退化通路采用 roll(X)、pitch(Y)、yaw(Z) 的 ZYX 顺序。

模型随姿态转动的红/绿/蓝箭头是设备 X/Y/Z；左下角固定小坐标架是世界参考，两个坐标架使用同一颜色。点击“显示归零”改变网页参考四元数，不向设备发送命令。采集数据、录制与导出保留原始坐标。姿态失效时不接受新的显示归零。

## 安装方向的边界

设备设置了非默认安装方向后，固件可能输出载体坐标下的姿态。物理壳体方向与载体输出方向不能混为一谈；需要依据已读回的安装方向表做明确映射，不能仅凭姿态数字猜测安装方式。模型当前采用产品默认安装坐标，非默认载体坐标需要前端明确标识或转换。

几何方向已由官方 CAD 和模块标识相互核对；数学测试检查旋转方向、四元数/欧拉角一致与显示归零。网页能加载并旋转模型不代表已经完成真实设备每个转轴的物理动作验收。

## 启动接入建议

启动脚本可先运行 `python scripts/prepare_model.py --install`，缓存验证成功后再启动 Host。准备失败时应把失败原因写到终端，并继续启动采集服务；三维窗口会显示缺失模型提示。不能在网页加载时自动执行 CAD 原生库或偷偷下载来源不明的替代模型。已有模型缓存时，准备程序不需要 CAD 包、网络或额外 venv，直接验证文件哈希。

Linux 与 Windows 采用同一转换脚本；首次安装需要可用的 Python/CAD wheel。依赖下载大于模型本身（OpenCascade/VTK），只在缺少缓存时发生。`DMIMU_MODEL_CACHE` 改变后，准备程序与后端应使用相同环境值。
