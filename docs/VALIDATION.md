# 验证记录

验证日期：2026-10-01；本机 Linux / Python 3.14.7。工作台由 Waitress 在 `127.0.0.1:5050` 运行，独立浏览器验证使用其他端口及合成数据，不切换真实设备的数据源。

## 软件验证

`python -m unittest discover -s tests -v` 共 **147 项测试**，覆盖：

- 测量帧与 V2 控制应答混合拆包、CRC、噪声重同步、非有限值、主模块与转发模块隔离。
- 单一串口所有者、来源切换、幂等恢复、V2 参数校验/ACK/回读/退出失败，以及校准启动与完成状态区别。
- 官方固件包元数据、分页 CRC、Boot ACK、超时/取消、身份核对、单次重启与版本回读；全部使用 fake serial，未擦写真实设备。
- 波形/频谱/轨迹的 CSV、MAT Level 5、XLSX；MAT 另外用独立 SciPy 读取核对数组、单位与时间，Excel 用 openpyxl 回读。
- 重叠 Allan 与独立标量算法、白噪声斜率、取消、时间诊断及多模块拒绝。
- 三维轨迹的静止、倾斜重力、恒加速度闭式解、同批时间戳、姿态过期、数据缺口、4 倍回放原始时基、点数边界；网页与 Agent 共用服务估计。
- 静止参考包含 2 kHz 重尾噪声及偶发加速度/角速度尖峰回归、持续转动/晃动/运动趋势拒绝、停止后恢复，以及可调参数原子校验；零速更新阈值独立。
- 官方 IMULOG01 双向容器转换、损坏/截断检测、流式导入/回放与稀疏索引定位。
- 浏览器 CSRF/Origin、Agent 独立鉴权、远程 HTTPS、凭据隐藏、设置原子校验、标准库 CLI 及当前轨迹下载。

Python 编译、前端模块 `node --check`、`python3 -S agent_cli.py --help` 与三个 Node 数学检查通过。GitHub Actions 为 Ubuntu / Windows × Python 3.11 / 3.14；实际运行状态以 GitHub 记录为准。

## 浏览器与性能

使用真实 Chromium，数据为演示或确定性合成信号：

- 波形共享时间轴、暂停快照、缩放/平移、双游标、Y 轴锁定、原始窗口导出和点数压力检查。
- FFT Web Worker：4096 点、Fs=1024 Hz，37 Hz / 2.5 幅值正弦峰值核对，91 Hz / 0.25 幅值第二轴核对；Hann/Hamming/矩形窗数学测试，DC/Nyquist 边界。线性/对数绘图、冻结状态、缺口及 Fs 不匹配拒绝、三种频谱导出通过。
- 三维模型加载、设备 XYZ 与世界坐标、四元数/Euler 变换、拖动观察与显示归零；轨迹独立数学及服务接线验证。
- Allan 合成录制分析完成与大数据取消，独立分析线程不阻塞串口操作队列。
- 固件拖放 14 项检查，只有上传/解析，没有任何升级、重启或参数 action。
- 浅/深色、六种强调色、中/英文、刷新率与 390 px 布局；页面无脚本错误。

流式回放测试包含超过 50 万帧；单独 108.36 MiB 合成记录索引约 0.54 秒、434 个检查点，定位约 1.16 ms，峰值 RSS 约 16.5 MiB。数值是本机单次检查，不是跨平台性能保证。HTTP 验证定位、generation 隔离与 4 倍回放仍保留原始 measurement_time。

## 真实设备与待验收范围

Type-C 接入后的 DM-IMU-L1 已实际枚举并接收测量帧。版本、22 字节配置和校准状态通过真实串口只读查询核对；原始应答、实际测量、用户照片与截图只保留本机，不进入仓库。

新版控制与升级协议依据固定版本官方 NativeAOT 上位机的封包、解析器与状态机还原，见 [V2 协议](V2_PROTOCOL.md) 与 [固件说明](FIRMWARE.md)。源码测试与模拟 ACK 不等于物理设备兼容验收。

本轮未对真实 IMU 执行校准、配置写入、航向归零、恢复出厂或升级擦写，未验证断电持久参数与物理噪声改善。没有外部位置真值验收轨迹精度；轨迹只提供短时惯性积分估计。非零安装方向的壳体与输出机体坐标映射尚未实机核验，界面保留提示。

Windows 启动/ACL 和软件 CI 无法替代 Windows COM 与官方 GUI 实测。官方录制容器已做字节格式与合成往返核对，尚未在官方 Windows EXE 中实际打开导出文件。
