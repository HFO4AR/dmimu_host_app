# 新版 USB 控制协议

独立实现来自 [达妙官方资料仓库](https://gitee.com/kit-miao/dm-imu) 固定提交 `ba758fd6106c2b210713bf1ef05800f1688f73c5`（2026-09-24）的 `上位机/dm-imu-upper.exe`。官方程序 SHA-256 为 `db5dae031697286256c1b2e27189a87c56f9b68a99d6d69829fdf0871a5776f2`。协议布局根据 NativeAOT 机器码封包、应答解析、调用路径核对；程序、CAD 和固件原文件只缓存本机，不随项目再分发。

## 请求与应答

```
请求: A5 | command:u8 | payload_length:u16-LE | payload | CRC16:u16-LE | 5A
应答: A5 | command:u8 | ACK_CODE:u8 | payload_length:u16-LE | payload | CRC16:u16-LE | 5A
```

CRC-16/CCITT-FALSE（0x1021，init FFFF，无反射，无最终 XOR）从 `command` 到 payload 结束，排除 A5、CRC 和 5A。请求长度 n+7，应答 n+8，官方应答 payload 上限 32。ACK_CODE=0 接受，非零报告设备拒绝，不猜测未公开错误码含义。

测量 55AA 与控制 A5 共用有界流解析器，可拆包、混合、CRC 校验和字节重同步。接收线程唯一读取串口，操作队列唯一提交请求，等待新鲜同命令 ACK；不为 V2 写操作自动重试。

| 命令 | payload / 作用 |
| --- | --- |
| 02 | 01 进入设置，00 退出 |
| 03 | 通道号0..4、开关：加速度、角速度、Euler、四元数、CAN主动发送 |
| 04 | 周期 uint16-LE，1..1000 ms |
| 05 / 06 | 加热开关 / 温度目标 uint8 |
| 07 / 08 | 从机 ID / 主机 ID uint8 |
| 09 | 输出接口 uint8：USB / RS485 / CAN / VOFA |
| 0A / 0B | CAN / UART 波特率表索引 uint8 |
| 0C / 0D | 保存参数 / 出厂恢复，空 payload |
| 0E | 读取版本，空 payload，返回8字节 |
| 10 | 读取配置，空 payload，返回17/18/22字节 |
| 11 / 12 | 启动静止校准 / 读取静止状态，空 payload |
| 13 | 00 开始六面，01 取消六面 |
| 14 | 读取六面状态，空 payload |
| 15 | 安装方向 uint8，0..23 |
| 16 | 加速度量程、陀螺量程，两个 uint8 |
| 17 | 航向归零，空 payload |

未核实的命令没有开放通用发送入口，也没有穷举未知写指令。

## 读取结构

版本8字节：0..3 Boot 四段，4..7 APP 四段，不作为单个 little-endian 整数解析。

配置17字节基础区：

| 偏移 | 内容 |
| --- | --- |
| 0..4 | 四个测量通道开关、CAN 主动发送 |
| 5 | 接口模式 |
| 6..7 | 周期 uint16-LE |
| 8 / 9 | 加热开关 / 目标温度 |
| 10..11 / 12..13 | 从机 / 主机 uint16-LE 回报（写入使用 uint8，限制0..255） |
| 14 / 15 | CAN / UART 波特率索引 |
| 16 | 保留模式枚举，0..3，未开放修改 |
| 17（若存在） | 安装方向，0..23 |
| 18..21（22字节） | 加速度量程/带宽、陀螺量程/带宽；带宽只回报，不开放未经核实的修改命令 |

CAN 表为 1000000、500000、400000、250000、200000、100000、50000、25000；UART 表为 9600、115200、230400、460800、500000、921600、1000000、1500000、2000000、2500000、3000000、3500000、4000000。未识别索引保留原 code，速率不猜默认值。

静止状态24字节：byte0 静止，byte1 state0..4，byte2 error0..3，byte3 保留；uint16@4/6 为样本数/目标数，uint16@8/10 ×0.01 为稳定值/阈值（deg/s）。state=3 时 int16@12/14/16 ×0.001 为偏置、uint16@18/20/22 ×0.001 为噪声（deg/s）。没有完成态，不把零-filled 字段当成有效结果。

六面状态21字节：byte0 state0..4，byte1 error0..4，byte2 完成面数0..6，byte3 当前面0..5或FF无，byte4 结果有效；uint16@5/7 样本数/目标数，int16@9/11/13 ×0.001 为偏置 m/s²，uint16@15/17/19 ×0.0001 为尺度系数。

## 操作语义

配置完整校验后进入设置模式，逐条等待 ACK，再读取配置、逐字段匹配，匹配才保存并退出。保存确认不等于断电持久化已验证。安装方向/量程变化标记需重新校准。

校准操作终态 `succeeded` 可以只表示**启动已确认**，此时 `completed=false`。后台查询设备状态，status中的 state=3/4 分别表示设备完成/失败；需要检查 error 和结果标记。指令超时/中断后返回未知结果，不重发校准。六面取消使用 13/01，不能反转为开始。
